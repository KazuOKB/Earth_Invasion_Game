# Earth Invasion Game

UFOを操作する横スクロールゲームです。
宇宙空間の障害物を避け、地球への到達を目指します。
Pygameで作られています。

現在、ゲームルールとコード構成の再設計を進めています。

- [新しいゲーム仕様](docs/game-design.md)
- [新しいコード設計](docs/architecture.md)
- [開発進捗と今後の計画](docs/progress.md)

新しい実装では、敵を倒して侵略ゲージをためます。
最後に地球防衛ボスを倒すとゲームクリアです。

## ゲーム内容

プレイヤーのUFOは画面左側を飛行します。
ステージは時間とともに右から左へ進みます。

1. 序盤では、右側から速度の異なる隕石が繰り返し飛来します。
2. 中盤では、隕石に加えて多数の小型敵が現れ、UFOの位置を追うように移動します。
3. 障害物に当たらず最後まで進むと地球が出現し、UFOが地球へ接近する演出の後にゲームクリアとなります。

隕石はビームで破壊できます。
追尾する小型敵もビームで破壊できます。
UFOが隕石または小型敵に接触するとゲームオーバーです。

現状は短編ゲームです。
スコア、残機、アイテム、難易度選択はありません。

## 操作方法

- `↑`: UFOを上へ移動
- `↓`: UFOを下へ移動
- `Z`: 前方へビームを発射（画面内に同時に出せるビームは1本）
- マウス: タイトル、ルール、リザルト画面のボタン操作

## 画面の流れ

```text
タイトル
├─ Game Start → ゲーム → ゲームクリア → タイトル
│                       └→ ゲームオーバー → タイトル
└─ Rule       → ルール説明 → タイトル
```

## 実行方法

Python 3.13とuvを使います。

最初に依存関係を準備します。

```bash
uv sync
```

現在のゲームを起動します。

```bash
uv run python MainFrame.py
```

画像は相対パスで読み込みます。
コマンドは、このリポジトリのルートディレクトリで実行してください。
ゲーム画面のサイズは750×500ピクセルです。

### 新しい実装の起動

通常用の設定で新しい画面を起動します。

```bash
uv run earth-invasion
```

短いテスト用の設定で起動します。

```bash
uv run earth-invasion --stage-profile test
```

現在はUFOの上下移動、ビーム、隕石との戦闘を確認できます。
`↑`と`↓`を押している間、UFOが一定速度で移動します。
UFOは画面の上下端で止まります。
`Z`を押している間、UFOが一定間隔でビームを発射します。
画面右側から、速度の異なる隕石が繰り返し出現します。
ビームが隕石に当たると、両方が消えます。
隕石を1個破壊すると、侵略ゲージが2増えます。
追尾敵の区間では、小型敵が0.8秒間隔で現れます。
追尾敵は左へ進みながらUFOを上下に追い、ビーム1発で破壊できます。
追尾敵を1体破壊すると、侵略ゲージが5増えます。
UFOが隕石または追尾敵に触れると、体力が1減って敵が消えます。
被弾後の1秒間は無敵になり、UFOが点滅します。
無敵中は追加のダメージを受けません。
体力が0になるとゲームオーバーになり、ゲームの更新が止まります。
ゲームオーバー画面で`R`を押すと、最初から再挑戦できます。
侵略ゲージは画面上部で確認できます。
通常設定では30秒、45秒、60秒で区間が進みます。
テスト設定では各区間が2秒で進みます。
終盤の時間と侵略ゲージの両条件を満たすと、表示がボス区間へ変わります。
現在の区間と残り秒数は画面上部で確認できます。
ウィンドウを変更しても、内部画面は750×500のままです。

画面を開かずに設定だけを確認できます。

```bash
uv run earth-invasion --stage-profile test --check-config
```

## ファイル構成

- `MainFrame.py`: Pygameの初期化、メインループ、画面遷移を管理するエントリーポイント
- `TopPanel.py`: タイトル画面
- `RulePanel.py`: ルール説明画面
- `GamePanel1.py`: プレイヤー、ビーム、敵、当たり判定、ステージ進行、クリア演出を含むメインゲーム
- `LosePanel.py`: ゲームオーバー画面
- `images/`: ゲームで使用する画像素材

以下は現在のゲーム本編からは使用されていない試作・代替実装です。

- `javateam.py`: UFOの移動とビーム発射を確認するための単独プロトタイプ
- `GamePanel2.py`: 将来拡張用として作られた未完成のゲーム画面
- `TopPanel_alt.py`: TkinterとPillowで作られたタイトル画面の代替案

## 現在の実装状況

現在のゲームは一通り操作できます。
ゲーム開始、ルール表示、クリア、ゲームオーバーを実装しています。
タイトルへ戻ることもできます。

ゲームバランス、演出、コード構成は再設計中です。
依存関係はuvで管理します。
pytest、Ruff、Mypyを使って新しい実装を確認します。

`src/earth_invasion/data/`には、新しいゲーム設定があります。
プレイヤー、ビーム、侵略ゲージ、ステージ時間を設定します。
現在の`GamePanel1.py`は、まだこの設定を読み込みません。

新しい実装では、ゲームを1秒に60回の固定間隔で更新します。
プレイヤー移動、ビーム、隕石、追尾敵、当たり判定、ステージ進行のルールはPygameから分離しています。
そのため、画面を開かずにゲームルールをテストできます。
