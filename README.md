# Earth Invasion Game

UFOを操作する横スクロールゲームです。
宇宙空間の障害物を避け、地球への到達を目指します。
Pygameで作られています。

現在、ゲームルールとコード構成の再設計を進めています。

- [新しいゲーム仕様](docs/game-design.md)
- [新しいコード設計](docs/architecture.md)
- [開発進捗と今後の計画](docs/progress.md)

新しい実装では、敵を倒して侵略ゲージをためます。
最後に地球防衛ボスを倒すとゲームクリアです。

## ゲーム内容

プレイヤーのUFOは画面左側を飛行します。
ステージは時間と侵略ゲージによって進みます。

1. 序盤では、右側から速度の異なる隕石が飛来します。
2. 中盤では、UFOを追う小型敵が現れます。
3. 終盤では、UFOへ弾を撃つ敵が現れます。
4. 時間と侵略ゲージの条件を満たすと、地球防衛ボスが現れます。
5. ボスを倒すとゲームクリアです。

敵をビームで破壊すると侵略ゲージが増えます。
UFOが敵や敵弾に触れると、体力が減ります。
体力が0になるとゲームオーバーです。
敵の撃破とボスへの攻撃でスコアが増えます。
ゲーム終了時に上位5件がランキングへ保存されます。

現状は短編ゲームです。
アイテムと難易度選択はありません。

## 操作方法

- タイトル画面の`Enter`: ゲーム開始
- タイトル画面の`R`: ルール表示
- タイトル画面の`Esc`: ゲーム終了
- タイトル画面の`↑`と`↓`: BGMまたは効果音を選択
- タイトル画面の`←`と`→`: 選択した音量を5%ずつ変更
- ルール画面の`Enter`または`Esc`: タイトルへ戻る
- ゲーム中の`↑`と`↓`: UFOを上下へ移動
- ゲーム中の`Z`: 押している間、ビームを発射
- ゲーム中の`Esc`: タイトルへ戻る
- 結果画面の`R`: 最初から再挑戦
- 結果画面の`Enter`または`Esc`: タイトルへ戻る

## 画面の流れ

```text
タイトル
├─ Game Start → ゲーム → ゲームクリア → タイトル
│                       └→ ゲームオーバー → タイトル
└─ Rule       → ルール説明 → タイトル
```

## デスクトップ版

Python 3.13とuvを使います。

最初に依存関係を準備します。

```bash
uv sync
```

コマンドは、このリポジトリのルートディレクトリで実行してください。
ゲーム画面のサイズは750×500ピクセルです。

### ゲームの起動

通常用の設定で新しい画面を起動します。

```bash
uv run earth-invasion
```

短いテスト用の設定で起動します。

```bash
uv run earth-invasion --stage-profile test
```

起動するとタイトル画面が表示されます。
タイトルからルールを確認し、ゲームを開始できます。
ゲームクリアとゲームオーバーは専用の結果画面に表示されます。
`↑`と`↓`を押している間、UFOが一定速度で移動します。
UFOは画面の上下端で止まります。
`Z`を押している間、UFOが一定間隔でビームを発射します。
ゲーム中は文字入力を無効にするため、IMEの変換窓は表示されません。
画面右側から、速度の異なる隕石が繰り返し出現します。
ビームが隕石に当たると、両方が消えます。
隕石を1個破壊すると、侵略ゲージが2増えます。
追尾敵の区間では、小型敵が1.1秒間隔で現れます。
追尾敵は左へ進みながらUFOを上下に追い、ビーム1発で破壊できます。
追尾敵を1体破壊すると、侵略ゲージが5増えます。
終盤では、紫色の攻撃敵が1.5秒間隔で現れます。
攻撃敵は左へ進み、1.2秒間隔でUFOへ向けて赤い弾を撃ちます。
攻撃敵を1体破壊すると、侵略ゲージが10増えます。
UFOが隕石、追尾敵、攻撃敵、敵弾に触れると、体力が1減ります。
体力は画面左上の3個のハートで確認できます。
被弾後の1.2秒間は無敵になり、UFOが点滅します。
被弾した瞬間はゲーム領域が短く赤く光ります。
無敵中は追加のダメージを受けません。
体力が0になるとゲームオーバーになり、ゲームの更新が止まります。
ゲームオーバー画面で`R`を押すと、最初から再挑戦できます。
`Enter`または`Esc`を押すと、タイトルへ戻ります。
侵略ゲージは画面上部で確認できます。
通常設定では20秒、25秒、30秒で区間が進みます。
テスト設定では各区間が2秒で進みます。
終盤の時間と侵略ゲージの両条件を満たすと、表示がボス区間へ変わります。
ボスは画面右側を上下に移動し、UFOへ向けて弾を撃ちます。
ボスへビームを12発当てるとゲームクリアです。
スコアの初期値は次のとおりです。

- 隕石: 100点
- 追尾敵: 300点
- 攻撃敵: 500点
- ボス命中: 100点
- ゲームクリア: 2000点

スコアは画面上部に表示します。
ゲームクリアまたはゲームオーバー時に上位5件だけを保存します。
ランキングはタイトル画面と結果画面に表示します。
保存先は`~/.earth_invasion/ranking.json`です。
通常設定と短いテスト設定のどちらもランキングへ保存します。
ゲームクリア画面で`R`を押すと、最初から再挑戦できます。
`Enter`または`Esc`を押すと、タイトルへ戻ります。
現在の区間と残り秒数は画面上部で確認できます。
画面上部100ピクセルはHUD専用領域です。
敵や弾はHUDへ入らず、宇宙背景の上に描画されます。
ビーム発射、敵破壊、ボスへの命中、接触、敵弾の被弾には効果音があります。
敵弾に当たった音は、敵本体や隕石へ接触した音と異なります。
タイトル、通常戦、ボス戦では、それぞれ明るいチップチューンBGMが流れます。
BGMと効果音の初期音量は0%です。
タイトル画面で別々に音量を調整できます。
効果音の音量を変更すると、確認用のビーム音が鳴ります。
音声デバイスを初期化できない環境では、無音のままゲームを続けます。
ウィンドウを変更しても、内部画面は750×500のままです。

画面を開かずに設定だけを確認できます。

```bash
uv run earth-invasion --stage-profile test --check-config
```

## ブラウザ版

公開URLは次の場所です。

<https://kazuokb.github.io/Earth_Invasion_Game/>

初回のPages設定やデプロイ中は、まだ表示できないことがあります。

### 開発中の起動

pygbag 0.9.3とWeb用Python 3.13を使います。

```bash
uv sync
uv run pygbag --PYBUILD 3.13 --width 750 --height 500 --title "Earth Invasion Game" .
```

起動後、ブラウザで<http://localhost:8000/>を開きます。
最初の読込後、画面をクリックするとゲームが始まります。

### リリース用ビルド

```bash
uv run pygbag --build --PYBUILD 3.13 --width 750 --height 500 --title "Earth Invasion Game" .
```

成果物は`build/web/`へ作られます。
`index.html`を直接開かず、HTTPサーバーから配信してください。

`master`へ変更が入ると、GitHub Actionsが同じビルドを実行します。
リポジトリのPages設定では、公開元に`GitHub Actions`を選びます。

### ブラウザ版の制約

- キーボード操作とゲーム内容はデスクトップ版と同じです。
- 音を使うには、読込後に画面をクリックする必要があります。
- 初期音量は0%です。タイトル画面で変更できます。
- ランキング保存はブラウザを閉じた後まで保証されません。
- WebAssemblyランタイムはpygbagの公式CDNから読み込みます。

### 開発用コマンド

```bash
uv run pytest
uv run ruff check main.py src tests scripts
uv run ruff format --check main.py src tests scripts
uv run mypy main.py src tests scripts
```

## ファイル構成

- `src/earth_invasion/gameplay/`: Pygameに依存しないゲームルール
- `src/earth_invasion/pygame_app/`: 入力、描画、画面遷移、音声
- `src/earth_invasion/data/`: スコア、ゲームバランス、ステージ時間の設定
- `src/earth_invasion/assets/`: 現在使用する画像とBGM
- `tests/`: ゲームルールとPygame側の自動テスト
- `docs/`: ゲーム仕様、コード設計、進捗
- `scripts/`: オリジナルBGMの生成スクリプト
- `main.py`: ブラウザ版の起動ファイル
- `pygbag.ini`: ブラウザ版へ含めるファイルの設定

## 現在の実装状況

現在のゲームは一通り操作できます。
ゲーム開始、ルール表示、クリア、ゲームオーバーを実装しています。
タイトルへ戻ることもできます。

ゲームバランスは最初の調整を終えています。
通常設定での試遊後に、必要なら再調整します。
依存関係はuvで管理します。
pytest、Ruff、Mypyを使って新しい実装を確認します。

`src/earth_invasion/data/`には、新しいゲーム設定があります。
プレイヤー、ビーム、侵略ゲージ、ステージ時間を設定します。

ゲームを1秒に60回の固定間隔で更新します。
プレイヤー移動、ビーム、3種類の敵、ボス、敵弾、当たり判定、ステージ進行のルールはPygameから分離しています。
そのため、画面を開かずにゲームルールをテストできます。
