## 2. 現在の方針

Python 3.13、Pygame、uvを使います。

ゲームルールはPygameから分離します。
画面を開かなくてもpytestで確認できる設計にします。

大きな変更を一度に入れません。
機能ごとに作業ブランチとDraft PRを作ります。
レビューとCIの成功後にSquash mergeします。

## 5. 現在の遊び方

通常設定で起動します。

```bash
uv run earth-invasion
```

短いテスト設定で起動します。

```bash
uv run earth-invasion --stage-profile test
```

操作は次のとおりです。

- `↑`: 上へ移動
- `↓`: 下へ移動
- `Z`: ビームを発射
- `R`: ゲームオーバー画面から再挑戦
- `Esc`: 現在の確認画面を閉じる

テスト設定では各区間が2秒で進みます。
追尾敵と接触ダメージを短時間で確認できます。
