## 2. 現在の方針

Python 3.13、Pygame、uvを使います。

ゲームルールはPygameから分離します。
画面を開かなくてもpytestで確認できる設計にします。

大きな変更を一度に入れません。
機能ごとに作業ブランチとDraft PRを作ります。
レビューとCIの成功後にSquash mergeします。

## 5. 現在の遊び方

通常設定で起動します。

```bash
uv run earth-invasion
```

短いテスト設定で起動します。

```bash
uv run earth-invasion --stage-profile test
```

操作は次のとおりです。

- タイトルの`Enter`: ゲーム開始
- タイトルの`R`: ルール表示
- タイトルの`Esc`: ゲーム終了
- ルールの`Enter`または`Esc`: タイトルへ戻る
- ゲーム中の`↑`と`↓`: 上下へ移動
- ゲーム中の`Z`: ビームを発射
- ゲーム中の`Esc`: タイトルへ戻る
- 結果画面の`R`: 最初から再挑戦
- 結果画面の`Enter`または`Esc`: タイトルへ戻る

テスト設定では各区間が2秒で進みます。
追尾敵、攻撃敵、ボス、敵弾、ゲームクリアを短時間で確認できます。

## 8. 品質確認

現在の自動テストは140件です。

ローカルでは次を実行します。

```bash
uv run pytest
uv run ruff check src tests
uv run ruff format --check src tests
uv run mypy src tests
uv lock --check
uv build
```

PRではGitHub Actionsが同じ検査と配布パッケージの確認を行います。
