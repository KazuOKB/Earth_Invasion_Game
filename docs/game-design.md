# ゲーム仕様書

## 1. この文書の目的

この文書は、新しいEarth Invasion Gameのルールをまとめます。

現在のゲームは参考として残します。
新しい実装は、この文書を基準に作ります。

## 2. ゲームの目標

プレイヤーはUFOを操作します。
地球の防衛部隊を倒し、侵略ゲージをためます。
最後に地球防衛ボスを倒すとゲームクリアです。

## 3. 基本の流れ

1. UFOを上下に動かします。
2. 敵の攻撃を避けます。
3. ビームで敵を倒します。
4. 敵を倒すと侵略ゲージが増えます。
5. 複数の区間を突破します。
6. 最後に地球防衛ボスと戦います。
7. ボスを倒すとゲームクリアです。

## 4. ステージ構成

ステージは次の順番で進みます。

### 序盤: 隕石

- 隕石が右から飛んできます。
- 隕石は1.2秒間隔で出現します。
- 隕石ごとの速度は1秒に180〜300ピクセルです。
- プレイヤーは隕石を避けます。
- 隕石はビームを1回当てると破壊できます。
- ビームと破壊した隕石は画面から消えます。
- 基本操作を覚える区間です。

### 中盤: 追尾する敵

- 敵がプレイヤーを追いかけます。
- 上下移動だけでは避けにくくなります。
- 敵を倒す判断が必要になります。

### 終盤: 攻撃してくる敵

- 敵が弾を発射します。
- 敵本体と敵の弾を避けます。
- ボス戦に向けて難しくなります。

### 最後: 地球防衛ボス

- 侵略ゲージが満タンになると、ボスを出現させられます。
- ボスには複数回の攻撃が必要です。
- ボスを倒すとゲームクリアです。
- ボス戦は時間では終了しません。

## 5. ステージ時間

ステージ時間はJSONで管理します。
Pythonコードには直接書きません。

通常用の設定は`src/earth_invasion/data/stages.normal.json`です。
短い動作確認には`src/earth_invasion/data/stages.test.json`を使います。

初期値は次のとおりです。

| 区間 | 通常用 | テスト用 |
|---|---:|---:|
| 隕石 | 30秒 | 2秒 |
| 追尾する敵 | 45秒 | 2秒 |
| 攻撃してくる敵 | 60秒 | 2秒 |
| ボス | 撃破まで | 撃破まで |

時間は後から調整できます。
区間の順番は変更しません。

ボスが出現するには、次の両方が必要です。

- 終盤の設定時間が過ぎている
- 侵略ゲージが満タンになっている

ゲージが先に満タンになっても、終盤までは進めます。
時間が先に過ぎた場合は、ゲージが満タンになるまで終盤を続けます。

## 6. 画面サイズ

ゲーム内部の大きさは750×500です。

ゲームは常にこの大きさで計算します。
ウィンドウだけを拡大または縮小します。

画面の縦横比は維持します。
余った部分は黒い余白にします。

この方法には次の利点があります。

- 当たり判定がウィンドウサイズに左右されません。
- 既存の画像を使いやすくなります。
- テストの座標を固定できます。

## 7. 画面の流れ

```text
タイトル
├─ ゲーム開始
│  ├─ 隕石
│  ├─ 追尾する敵
│  ├─ 攻撃してくる敵
│  ├─ ボス
│  ├─ ゲームクリア
│  └─ ゲームオーバー
└─ ルール説明
```

ゲームクリアとゲームオーバーの画面から再挑戦できます。
タイトルへ戻ることもできます。

## 8. ゲームクリア条件

地球防衛ボスを倒すとゲームクリアです。

侵略ゲージが満タンになることが、ボスの出現条件です。

侵略ゲージの初期値は次のとおりです。

- 通常用の最大値: 100
- テスト用の最大値: 10
- 隕石を破壊: 2増える
- 追尾する敵を倒す: 5増える
- 攻撃する敵を倒す: 10増える

これらの値は設定ファイルから変更できます。
侵略ゲージは最大値を超えません。

## 9. ゲームオーバー条件

プレイヤーの体力が0になるとゲームオーバーです。

- 最大体力: 3
- 被弾後の無敵時間: 1秒
- 無敵中の表示: UFOを点滅させる

無敵中は追加のダメージを受けません。

## 10. 操作

最初の実装では、次の操作を使います。

- `↑`: 上へ移動
- `↓`: 下へ移動
- `Z`: 押している間、ビームを発射
- `Esc`: ポーズ

UFOの上下移動速度は1秒に240ピクセルです。
UFOの横位置は固定します。
UFOは画面の上下端より外へ移動できません。

ビームの発射間隔は0.25秒です。
ビームの移動速度は1秒に600ピクセルです。
`Z`を押すと最初のビームをすぐに発射します。
画面内の弾数は制限しません。
画面外へ出た弾は削除します。

ダッシュや特殊攻撃は最初から追加しません。
必要になったときに検討します。

## 11. 最初の完成条件

次の項目が動けば、最初の完成版とします。

- タイトルからゲームを開始できる
- UFOを上下に動かせる
- ビームを発射できる
- 4つの区間が順番に進む
- 敵を倒すと侵略ゲージが増える
- プレイヤーがダメージを受ける
- ボスを倒すとクリアになる
- 体力が0になるとゲームオーバーになる
- クリア後とゲームオーバー後に再挑戦できる
- 通常用とテスト用の時間設定を切り替えられる
- ウィンドウを変更してもゲーム内部の座標が変わらない
