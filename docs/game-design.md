# ゲーム仕様書

## 1. この文書の目的

この文書は、新しいEarth Invasion Gameのルールをまとめます。

現在のゲームは参考として残します。
新しい実装は、この文書を基準に作ります。

## 2. ゲームの目標

プレイヤーはUFOを操作します。
地球の防衛部隊を倒し、侵略ゲージをためます。
最後に地球防衛ボスを倒すとゲームクリアです。

## 3. 基本の流れ

1. UFOを上下に動かします。
2. 敵の攻撃を避けます。
3. ビームで敵を倒します。
4. 敵を倒すと侵略ゲージが増えます。
5. 複数の区間を突破します。
6. 最後に地球防衛ボスと戦います。
7. ボスを倒すとゲームクリアです。

## 4. ステージ構成

ステージは次の順番で進みます。

### 序盤: 隕石

- 隕石が右から飛んできます。
- 隕石は1.2秒間隔で出現します。
- 隕石ごとの速度は1秒に180〜300ピクセルです。
- プレイヤーは隕石を避けます。
- 隕石はビームを1回当てると破壊できます。
- ビームと破壊した隕石は画面から消えます。
- 基本操作を覚える区間です。

### 中盤: 追尾する敵

- 追尾敵は0.8秒間隔で出現します。
- 追尾敵は左へ1秒に240ピクセル進みます。
- UFOへ向かう上下速度は1秒に180ピクセルです。
- 敵がプレイヤーを追いかけます。
- 上下移動だけでは避けにくくなります。
- 追尾敵はビームを1回当てると破壊できます。
- 敵を倒す判断が必要になります。

### 終盤: 攻撃してくる敵

- 攻撃敵は1秒間隔で出現します。
- 攻撃敵は左へ1秒に120ピクセル進みます。
- 攻撃敵は0.8秒間隔で弾を発射します。
- 発射時のUFOの位置へ向けて弾を飛ばします。
- 敵弾の速度は1秒に300ピクセルです。
- 敵本体と敵の弾を避けます。
- 攻撃敵はビームを1回当てると破壊できます。
- ボス戦に向けて難しくなります。

### 最後: 地球防衛ボス

- 侵略ゲージが満タンになると、ボスを出現させられます。
- ボスの最大体力は20です。
- ボスは画面右側を上下に往復します。
- ボスの上下速度は1秒に100ピクセルです。
- ボスは0.6秒間隔でUFOへ向けて弾を発射します。
- ボスの弾の速度は1秒に360ピクセルです。
- ビーム1発でボスの体力を1減らします。
- ボスを倒すとゲームクリアです。
- ボス戦は時間では終了しません。

## 5. ステージ時間

ステージ時間はJSONで管理します。
Pythonコードには直接書きません。

通常用の設定は`src/earth_invasion/data/stages.normal.json`です。
短い動作確認には`src/earth_invasion/data/stages.test.json`を使います。

初期値は次のとおりです。

| 区間 | 通常用 | テスト用 |
|---|---:|---:|
| 隕石 | 30秒 | 2秒 |
| 追尾する敵 | 45秒 | 2秒 |
| 攻撃してくる敵 | 60秒 | 2秒 |
| ボス | 撃破まで | 撃破まで |

時間は後から調整できます。
区間の順番は変更しません。

ボスが出現するには、次の両方が必要です。

- 終盤の設定時間が過ぎている
- 侵略ゲージが満タンになっている

ゲージが先に満タンになっても、終盤までは進めます。
時間が先に過ぎた場合は、ゲージが満タンになるまで終盤を続けます。

## 6. 画面サイズ

ゲーム内部の大きさは750×500です。

ゲームは常にこの大きさで計算します。
ウィンドウだけを拡大または縮小します。

画面上部100ピクセルはHUD専用領域です。
プレイヤー、敵、ボス、弾は、その下のゲーム領域だけを移動します。
HUDはゲーム内物体より後に描画し、文字やゲージとの重なりを防ぎます。

背景には宇宙画像を表示します。
背景画像も750×500の内部画面へ合わせてから描画します。

画面の縦横比は維持します。
余った部分は黒い余白にします。

この方法には次の利点があります。

- 当たり判定がウィンドウサイズに左右されません。
- 既存の画像を使いやすくなります。
- テストの座標を固定できます。

## 7. 画面の流れ

```text
タイトル
├─ ゲーム開始
│  ├─ 隕石
│  ├─ 追尾する敵
│  ├─ 攻撃してくる敵
│  ├─ ボス
│  ├─ ゲームクリア
│  └─ ゲームオーバー
└─ ルール説明
```

ゲームクリアとゲームオーバーの画面から再挑戦できます。
タイトルへ戻ることもできます。

各画面の操作は次のとおりです。

- タイトルの`Enter`: ゲームを開始する
- タイトルの`R`: ルールを表示する
- タイトルの`Esc`: ゲームを終了する
- タイトルの`↑`と`↓`: BGMまたは効果音を選択する
- タイトルの`←`と`→`: 選択した音量を10%ずつ変更する
- ルールの`Enter`または`Esc`: タイトルへ戻る
- ゲーム中の`Esc`: タイトルへ戻る
- 結果画面の`R`: 最初から再挑戦する
- 結果画面の`Enter`または`Esc`: タイトルへ戻る

## 8. ゲームクリア条件

地球防衛ボスを倒すとゲームクリアです。

侵略ゲージが満タンになることが、ボスの出現条件です。
ゲームクリア中はプレイヤー、敵、弾、区間時間を更新しません。
`R`を押すと最初から再挑戦できます。

侵略ゲージの初期値は次のとおりです。

- 通常用の最大値: 100
- テスト用の最大値: 10
- 隕石を破壊: 2増える
- 追尾する敵を倒す: 5増える
- 攻撃する敵を倒す: 10増える

これらの値は設定ファイルから変更できます。
侵略ゲージは最大値を超えません。

## 9. ゲームオーバー条件

プレイヤーの体力が0になるとゲームオーバーです。

- 最大体力: 3
- 体力表示: 3個のハート
- 被弾後の無敵時間: 1秒
- 無敵中の表示: UFOを点滅させる
- 被弾時の表示: ゲーム領域を短く赤くする

無敵中は追加のダメージを受けません。
ダメージを受けると、失った体力分のハートが空表示になります。
再挑戦すると3個のハートが満たされた状態へ戻ります。

隕石、追尾敵、攻撃敵、敵弾との接触では、次の処理を行います。

- プレイヤーの体力を1減らす
- 接触した敵を消す
- 接触した敵弾を消す
- 同時に複数の敵へ触れても、体力は1だけ減らす
- 無敵中は敵だけを消し、体力は減らさない

体力が0になるとゲームオーバー画面を表示します。
ゲームオーバー中は、プレイヤー、敵、弾、区間時間を更新しません。
`R`を押すと、体力、敵、弾、侵略ゲージ、区間を初期化して再挑戦します。

## 10. 操作

最初の実装では、次の操作を使います。

- `↑`: 上へ移動
- `↓`: 下へ移動
- `Z`: 押している間、ビームを発射
- `Esc`: ゲーム中にタイトルへ戻る

結果画面では`R`で再挑戦できます。
タイトル、ルール、結果画面の操作は「7. 画面の流れ」にまとめています。

UFOの上下移動速度は1秒に240ピクセルです。
UFOの横位置は固定します。
UFOは画面の上下端より外へ移動できません。

ビームの発射間隔は0.25秒です。
ビームの移動速度は1秒に600ピクセルです。
`Z`を押すと最初のビームをすぐに発射します。
画面内の弾数は制限しません。
画面外へ出た弾は削除します。

ダッシュや特殊攻撃は最初から追加しません。
必要になったときに検討します。

## 11. 最初の完成条件

次の項目が動けば、最初の完成版とします。

- タイトルからゲームを開始できる
- UFOを上下に動かせる
- ビームを発射できる
- 4つの区間が順番に進む
- 敵を倒すと侵略ゲージが増える
- プレイヤーがダメージを受ける
- ボスを倒すとクリアになる
- 体力が0になるとゲームオーバーになる
- クリア後とゲームオーバー後に再挑戦できる
- 通常用とテスト用の時間設定を切り替えられる
- ウィンドウを変更してもゲーム内部の座標が変わらない

## 12. まだ決めていないこと

次の内容は、実装前または試遊後に決めます。

- スコアとハイスコアの扱い
- 難易度選択

ビーム発射、敵破壊、ボスへの命中、被弾には短い効果音を付けます。
敵弾に当たった場合は、敵本体や隕石へ接触した場合とは異なる音を鳴らします。
効果音はゲームルールと分け、Pygame側で再生します。

BGMは明るいチップチューンにします。
タイトル、通常戦、ボス戦で曲を切り替えます。
ゲームクリアとゲームオーバーではタイトル曲へ戻します。
音源はこのプロジェクトの生成スクリプトで作るオリジナル曲です。

BGMと効果音の初期音量は0%です。
タイトル画面で別々に0%から100%まで調整できます。
変更した音量はゲームを終了するまで有効です。

決まっていない内容は、最初から複雑に作りません。
